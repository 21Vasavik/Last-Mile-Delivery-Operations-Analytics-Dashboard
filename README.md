# Last-Mile Delivery Operations Analytics

## Project Overview

This project analyzes last-mile delivery operations for QuickRoute Logistics using Power BI.

The objective is to transform operational data into an interactive dashboard that helps understand delivery demand, customer behaviour, delivery performance, driver and vehicle performance, and delivery problems.

## Tools & Technologies

- Power BI
- Power Query
- DAX
- Data Modeling
- Data Visualization

## Project Objectives

1. Understand Delivery Demand
2. Understand Customer Order Behaviour
3. Evaluate Delivery Performance
4. Understand Driver and Vehicle Performance
5. Identify Delivery Problems

## Data Preparation

The data was cleaned and transformed using Power Query.

Key preparation activities included:

- Text cleaning and standardization
- Handling blanks
- Checking duplicate IDs
- Data type validation
- Creating relationships between tables
- Date table integration

## Data Model

The project contains the following main tables:

- Customers
- Orders
- Deliveries
- Drivers
- Vehicles
- Date Table

Relationships were created to support cross-table analysis.

## Key KPIs

- Total Orders
- Total Order Value
- Total Deliveries
- Delivery Success %
- Failed Deliveries
- Multiple Attempt Deliveries
- Average Delivery Duration
- Deliveries per Driver
- Deliveries per Vehicle

## Dashboard Pages

### 1. Delivery Demand
Analyzes order volume, order trends, delivery zones, service types and priorities.

### 2. Customer Behaviour
Analyzes customer participation, order frequency, customer type and order value.

### 3. Delivery Performance
Analyzes delivery success, failed deliveries, delivery duration and delivery status.

### 4. Driver & Vehicle Performance
Analyzes driver workload, driver ratings, vehicle utilization and delivery outcomes.

### 5. Delivery Problems
Analyzes failed deliveries, multiple attempts, pending deliveries and problem zones.

### 6. Executive Summary
Provides a consolidated management-level view of the key findings across all objectives.
